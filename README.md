# Precursor manuscript for Rescue Boat

This repository preserves the **source precursor manuscript** for the public [Rescue Boat](https://github.com/daniel-lingar/rescue-boat) publication. It contains an expanded manuscript draft, including material that was later selected, reorganized, or extracted into the locked 10-article Rescue Boat edition and its supporting content files.

The canonical current publication is maintained in `rescue-boat`. This repository is retained for historical/source reference and is not the active public edition.
